# MediQueue

MediQueue is a clinic management and queue management mobile application built with React Native. The system is designed to help clinics, healthcare workers, patients, and pharmacies manage appointments, queues, consultations, patient records, and medication reminders more efficiently.

## Project Purpose

The purpose of MediQueue is to reduce long waiting times in clinics and improve the way patients move through healthcare services. The application provides a digital approach to appointment booking, queue tracking, consultation history, patient records, and medication management.

## Main Features

- Patient registration and login.
- Doctor and patient dashboards.
- Appointment booking and appointment management.
- Patient queue tracking.
- Consultation history management.
- Patient records management.
- Medication reminders and medication history.
- Pharmacy-related patient support.
- Firebase integration for authentication and data storage.

## Getting Started

Install dependencies:

```sh
npm install
```

Start Metro:

```sh
npm start
```

Run the Android app:

```sh
npm run android
```
