# MediQueue Release

## Version

MediQueue v1.0.0

## Download

Download the Android APK from this folder:

`MediQueue-v1.0.0.apk`

## Installation

1. Download `MediQueue-v1.0.0.apk` to an Android phone.
2. Open the downloaded file.
3. If Android asks for permission, allow installation from the browser or file manager.
4. Tap Install.
5. Open MediQueue after installation.

## Notes

- This APK is for Android phones.
- The package name is `com.mediqueue`.
- The app version is `1.0`.
- Because this APK is not installed from Google Play Store, Android may show an "unknown app" warning during installation.
